# Getting Support for AETHER

Welcome to the AETHER community. If you need assistance, encounter a problem, or have an idea, here is how you can find help.

---

## Documentation and Guides

Before filing an issue, check out our comprehensive guides in the [`docs/`](docs/) directory:

- **[Installation & Setup Guide](docs/SETUP.md)**: Step-by-step instructions for running the web workspace and desktop clients.
- **[Agent Computers & Sandboxing](docs/COMPUTERS.md)**: Setting up isolated Docker environments for autonomous web browsing and shell execution.
- **[System Architecture](docs/ARCHITECTURE.md)**: Deep dive into AETHER's multi-platform architecture and IPC communications.
- **[Telemetry & Privacy](docs/SETUP-TELEMETRY.md)**: How to configure telemetry and privacy flags (`DO_NOT_TRACK`).

---

## Reporting Bugs

If you find a bug or unexpected behavior:

1. Search existing [GitHub Issues](https://github.com/soumyachk101/AETHER/issues) to see if the issue has already been reported.
2. If not, open a new issue using our bug report template.
3. Include:
   - Operating system and version (macOS, Linux, Windows).
   - Component (`AETHER-web`, `AETHER-swift`, or `AETHER-rust`).
   - Node.js, Rust, or Swift version.
   - Clear reproduction steps and relevant console logs.

---

## Requesting Features

Have an idea to make AETHER better?

- Open a feature request on [GitHub Issues](https://github.com/soumyachk101/AETHER/issues).
- Describe the problem your feature solves and how you envision it working.

## Security Vulnerabilities

Please do not submit security vulnerabilities through public GitHub issues. Follow the private reporting process detailed in our [Security Policy](SECURITY.md) by emailing `soumya.chk101@gmail.com`.
